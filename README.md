## Featured Projects

### [Enterprise AWS Three-Tier Web Architecture](https://github.com/shiva-ram9/aws-three-tier-architecture)

Production-style architecture deployed in AWS Hyderabad (`ap-south-2`) with six subnets across two Availability Zones.

**Built with:** VPC · EC2 · Application Load Balancer · Auto Scaling · RDS MySQL · IAM · Systems Manager · CloudWatch

**What it demonstrates:**

- Segmented public, private application, and private database tiers
- EC2 instances without public IP addresses, administered through Systems Manager
- Security-group chaining from ALB → application → RDS
- Auto Scaling across two Availability Zones with healthy targets and HTTP 200 validation
- Verified EC2-to-RDS connectivity and CloudWatch monitoring
- Architecture, deployment, security, validation documentation, and AWS console evidence
